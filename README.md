## عن المشروع

مشروع لتطوير نموذج يرصد العرنجية في النصوص العربية ويحدد مواضعها، اعتمادًا على بيانات لغوية موثقة ومعايير واضحة للتصنيف. وتشمل الظاهرة التأثر بأنماط أجنبية في استعمال الألفاظ وبناء التراكيب والأساليب.

يمتد العمل من جمع البيانات ومراجعتها إلى مقارنة النماذج وتطويرها وتقييمها، مع اقتراح صياغات عربية بديلة في مرحلة لاحقة.

## مراحل العمل

1. **إعداد البيانات:** جمع الأمثلة، وتوثيق مصادرها، ووصف ظواهرها، ومراجعة تصنيفاتها وبدائلها.
2. **تقييم النماذج:** اختبار قدرتها على التصنيف وتحديد مواضع الظاهرة، ومقارنة طرق توجيهها وتحليل أخطائها.
3. **توسيع البيانات وتطوير النموذج:** تجربة توليد أمثلة إضافية ومراجعتها، ثم دراسة تدريب نموذج مخصص وتقييم أثر البيانات المضافة.
4. **اقتراح البدائل:** تطوير إعادة الصياغة مع الحفاظ على المعنى، بعد تقييم التصنيف واعتماد نطاق هذه المرحلة.

## التقدم الحالي

- تنظيم **٤٤٠ سجلًا** تشمل ألفاظًا وتراكيب وأساليب، مع التصنيف والظاهرة والمصدر والصياغة البديلة وحالة المراجعة.
- إجراء تجربتين أوليتين للتصنيف، دون أمثلة ومع أمثلة، على **٢٤ جملة**.
- توثيق البرومبتات والنتائج وتحليل مواضع الاختلاف مع التسميات المقترحة.

العمل حاليًا في مرحلة إعداد البيانات والتقييم الأولي؛ ولم يُعتمد نموذج نهائي بعد. تفاصيل التجارب ونتائجها في [التقارير](reports/).
