# العرنجية

مشروع لدراسة تعبيرات عربية تأثرت في ألفاظها أو تراكيبها أو أساليبها بأنماط أجنبية، واختبار قدرة النماذج اللغوية على تمييزها في سياقها.

يبدأ العمل من الأمثلة ومصادرها، ثم ينتقل إلى ضبط معيار التصنيف وتجربته. أما توليد بيانات إضافية وتدريب نموذج مخصص فهما خطوتان لاحقتان تتوقفان على نتائج التقييم.

**المرحلة الحالية:** إعداد البيانات وتجارب التصنيف الأولية.

---

## الفكرة

قد يكون التعبير مألوفًا، ومع ذلك يستحق فحص طريقة بنائه أو دلالته. وقد يكون له مقابل أجنبي أو بديل عربي أقصر دون أن يكفي ذلك للحكم عليه بالعرنجية.

لذلك لا يقتصر المشروع على جمع عبارات وتصنيفها؛ بل يهتم بتحديد الظاهرة، وتوثيق المصدر، ومراعاة السياق، وفصل الحالات المحسومة عن الحالات التي تحتاج إلى مراجعة.

## ما أُنجز حتى الآن

| الجانب | العمل المنجز |
| :--- | :--- |
| جمع البيانات | تنظيم **٤٤٠ سجلًا** من مصادر لغوية ومجتمعية متعددة |
| بنية البيانات | ربط كل سجل بمعرّف، وتصنيف، ونوع، وظاهرة، ومصدر، وحالة مراجعة |
| إعداد التجربة | اختيار **٢٤ جملة**: ١٢ أصلًا من البيانات و١٢ صياغة بديلة مرتبطة بها |
| التوجيه | إعداد تجربة دون أمثلة، وأخرى تتضمن **٦ أمثلة محلولة** خارج مجموعة الاختبار |
| تحليل المخرجات | مقارنة التصنيفات والتعليلات، وتحديد مواضع اختلاف النموذج مع المعيار الأولي |

> تصنيفات المصادر وأحكام البدائل لا تُعرض بوصفها مرجعًا لغويًا نهائيًا. البدائل في الاختبار تحمل تسميات مقترحة تحتاج إلى اعتماد مستقل.

## البيانات

تضم المجموعة ألفاظًا وتراكيب وأساليب. بعض السجلات جمل مكتملة، وبعضها عبارات قصيرة؛ لذلك تختلف حاجتها إلى السياق.

| الحقل | الغرض منه |
| :--- | :--- |
| المعرّف | تتبع السجل، مثل `ARJ_00001` |
| الجملة الأصلية | النص كما جُمع من المصدر |
| الأصل الأجنبي | المقابل المدون في المصدر أو أثناء التجهيز؛ لا يثبت بمفرده الأصل التاريخي |
| التصنيف | عرنجية، أو غير عرنجية، أو غير محسوم |
| العبارة العرنجية | الموضع المشار إليه داخل النص |
| النوع والظاهرة | وصف النمط اللغوي محل الدراسة |
| الصياغة البديلة | البديل المدون، مع مراعاة تكافؤ المعنى عند المراجعة |
| المصدر والصفحة | تتبع المثال والرجوع إلى مرجعه |
| حالة المراجعة | توثيق وضع الحكم والملاحظات المتعلقة به |

## التجارب الأولى

جرى اختبار الجمل دفعة واحدة، ثم تكرار الاختبار بعد إضافة أمثلة محلولة، مع إبقاء جمل الاختبار وترتيبها كما هما.

| المخرج | دون أمثلة · Zero-shot | مع أمثلة · Few-shot |
| :--- | :---: | :---: |
| عرنجية | ٠ | ٠ |
| غير عرنجية | ١٩ | ٢٣ |
| غير محسوم | ٥ | ١ |
| المطابقة للتسميات المقترحة | ١٢ من ٢٤ | ١٢ من ٢٤ |

لم تتحسن المطابقة في هاتين الجولتين؛ انخفض عدد الحالات غير المحسومة دون ظهور تصنيفات موجبة للعرنجية. وتشير التعليلات إلى اختلاف محتمل بين معيار النموذج ومعيار المجموعة، إلى جانب محدودية الأمثلة المقدمة.

أمثلة البرومبت تمثل ثلاث ظواهر لا تتطابق مباشرة مع ظواهر الاختبار. لذلك لا تختبر هذه الجولة جميع حالات تطبيق الظواهر الممثلة، ولا تكفي للحكم العام على قدرة النموذج أو ملاءمته لتوليد بيانات جديدة.

## الخطوات القادمة

- [x] جمع الأمثلة وتنظيم حقولها.
- [x] إجراء جولتين أوليتين للتصنيف.
- [ ] تثبيت معيار الحكم ومراجعة الأحكام المرجعية.
- [ ] اختبار جمل جديدة من الظواهر الممثلة في البرومبت.
- [ ] مقارنة إعدادات التوجيه ونماذج أخرى على اختبار محفوظ.
- [ ] تجربة توليد بيانات إضافية ومراجعتها بعد تقييم التصنيف.
- [ ] دراسة تدريب نموذج مخصص وتقييم أثر البيانات الإضافية.

## تنظيم العمل

هذا تنظيم مقترح عند جمع ملفات المشروع في المستودع:

| المجلد | المحتوى |
| :--- | :--- |
| `data/source/` | نسخة البيانات الأصلية |
| `data/prepared/` | نسخ البيانات المجهزة مع توثيق التعديلات |
| `prompts/` | نصوص البرومبتات وإصداراتها |
| `experiments/` | المدخلات، والأحكام المرجعية، والردود، وملخصات التشغيل |
| `scripts/` | أكواد التجهيز والتقييم |
| `reports/` | التقارير والعروض |
| `docs/` | توثيق المنهج والتجارب |
| `assets/` | العناصر البصرية المستخدمة في هذا الملف |

## مراجع المنهج

- [Inter-Coder Agreement — Artstein & Poesio, 2008](https://aclanthology.org/J08-4004/) — اتفاق المراجعين على التسميات.
- [Calibrate Before Use — Zhao et al., 2021](https://proceedings.mlr.press/v139/zhao21c.html) — حساسية التوجيه للأمثلة والصياغة.
- [CheckList — Ribeiro et al., 2020](https://aclanthology.org/2020.acl-main.442/) — الاختبارات السلوكية الموجهة.
- [HELM — Liang et al.](https://arxiv.org/abs/2211.09110) — توثيق التقييم وتوحيد ظروف المقارنة.
